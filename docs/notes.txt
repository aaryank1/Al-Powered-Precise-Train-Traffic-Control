What is a train traffic controller?
    - An actual human making real-time decisions based on experience,
      operating rules, current delays, and infrastructure constraints.
    - The project is trying to build decision-support logic for this role.

What is a Railway Section?
    - A section is a stretch of railway track managed by a particular controller.
    Example:
        Mumbai ---- Thane ---- Kalyan ---- Kasara
        One controller might manage:
        Thane ---- Kalyan ---- Kasara

What is a Tick?
    - One tick is one decision cycle and 30 simulated seconds.
    - A train can occupy a block across multiple ticks.
    - Scheduled station dwell currently lasts one tick (30 seconds).

What is a Block Section?
    - This is one of the most important concepts.
    - A railway track is divided into blocks.
    Example:
        A ----- B ----- C ----- D
        Actually becomes:
            [A-B] [B-C] [C-D]
        Each bracket is a block.
    Rule:
        - Only ONE train can hold a directional block until it arrives.
        - UP and DOWN blocks between the same stations are separate parallel
          resources, so one train may use each at the same time.

What is Occupancy?
    - Occupancy means which train currently owns a railway resource.
    - In this project the resources are:
        UP and DOWN station main lines,
        UP and DOWN station loop lines where configured,
        persistent directional block reservations during travel,
        destination-line reservations for approaching trains.
    - Safety starts by asking: is the resource free before the train uses it?

What is a Loop Line?
    - Suppose station B has extra track.
        Main Line
            -----------------
        Loop Line
            \_______/
    - A train can be parked in the loop while another train passes on the main
      line.

What is a Crossing?
    - Crossing occurs on a single-line section.
    Example:
        A ---- B ---- C
        Express at A
        Passenger at C
        Both need to pass each other.
    Solution:
        Express and passenger meet near a loop-capable station.
        Lower-priority train enters the loop.
        Higher-priority train passes on the main line.
        Lower-priority train exits the loop and continues.
    - The current project is now a double-line section, so opposing trains use
      separate UP and DOWN mains and do not need a loop to cross.
    - Current loop behavior instead supports overtaking in the same direction.

What is Headway?
    - Headway is the minimum safe spacing between trains.
    - Current v3 keeps one train in each directional block until arrival, but
      does not yet model a separate time-headway after the block clears.
    - Future versions can model time gaps between consecutive trains using the
      same block.

What is a Route?
    - A route is the next safe action selected for a train based on the network,
      occupancy state, and operating rules.
    - Current actions are:
        MOVE,
        WAIT,
        DWELL,
        ENTER_LOOP,
        EXIT_LOOP,
        ARRIVE.

What is a Conflict?
    - A conflict happens when a desired movement is not safe because a required
      resource is already occupied or reserved.
    - Examples:
        target station main line occupied,
        block already reserved,
        no directional loop available for an overtake.

What is a Control Chart ?
    - A manual chart that traffic controllers use to make real time decisions 
    - Distance stations are plotted on the Y-axis and Time (24 hours) is plotted on the X-axis. The trajectory of a train forms a diagonal line.

UP and DOWN are designated railway directions, not compass directions.
For this model, Virar -> Dadar is UP and Dadar -> Virar is DOWN.
Every station has an UP main and DOWN main. Borivali and Andheri also have an
UP loop and DOWN loop. See docs/network_lines.md for the full explanation.

Distant signal, home signal, starter signal, advanced starter.
The exact signal sequence depends on the station and signalling system; the
advanced starter generally controls departure into the block section.

Railway signalling does not depend on consumer-style GPS position. Track
circuits or axle-counter sections detect whether a protected track section is
occupied. An axle counter compares axle counts at section entry and exit to
prove the section clear; it does not provide continuous GPS-like train location.
